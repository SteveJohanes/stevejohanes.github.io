Panelia

Panelia is a web-based comic reading platform designed to provide an engaging way for users to discover and explore comics.

Type
Website
Status
In progress
Built with
Next.js, React, Firebase

Goals

  • Provide an engaging and visually appealing platform for discovering comics.
  • Organize comic information, including posters, reading status, ratings, genres, and episode counts.
  • Simplify comic content management through an admin panel.
  • Provide tools for administrators to manage genres and publish announcements.

Key features

  • Comic catalog with poster images and visual comic cards
  • Comic reading status, ratings, genres, and episode counts
  • Comic-panel-inspired home page design
  • Admin panel for managing comic content
  • Genre management
  • Announcement management
  • Admin authentication and login
